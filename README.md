BienvenuePlugin is a simple and efficient Minecraft plugin that allows players to welcome new arrivals using the /bvn command. Players are rewarded for welcoming new players,
while a built-in leaderboard tracks the most welcoming members of the community. Perfect for encouraging teamwork, friendliness, and creating a welcoming atmosphere on your server. 🚀

WARNING: The plugin does not notify you when a new update is available. To stay informed about updates and patch notes, you must join the Discord server below.
